# Gallina Gardens Website

Official website for **Gallina Gardens** — friendly garden care rooted in Cornwall.

**Live site:** [gallinagardens.co.uk](https://gallinagardens.co.uk)

---

## About this project

This is a single-page website built in HTML, CSS and JavaScript.  
All images and assets are embedded directly in `index.html` so there are no external files to manage.

---

## Files in this project

| File | What it does |
|------|--------------|
| `index.html` | The entire website — all pages, styles and scripts |
| `README.md` | This file — describes the project on GitHub |
| `.gitignore` | Tells Git to ignore files that shouldn't be uploaded |
| `CNAME` | Tells GitHub Pages to serve the site at gallinagardens.co.uk |

---

## Making changes

1. Open `index.html` in a text editor (see instructions below)
2. Make your changes
3. Upload the updated file to GitHub (drag and drop to replace the old one)
4. The live site updates automatically within 60 seconds

### Recommended free text editors
- **Visual Studio Code** — code.visualstudio.com (best option, free)
- **Notepad++** — notepad-plus-plus.org (simpler, Windows only)

---

## Before going live — two things to update in index.html

Open `index.html` in a text editor and do a Find & Replace (Ctrl+H):

1. Replace `YOUR_FORMSPREE_FORM_ID` with your actual Formspree form ID  
   (looks like: `xpwzabcd`)

2. Replace `YOUR_RECAPTCHA_SITE_KEY` with your actual Google reCAPTCHA site key  
   (looks like: `6Lc_xxxxxxxxxxxxxxxxxxxxxx`)
